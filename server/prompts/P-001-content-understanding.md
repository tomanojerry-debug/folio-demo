# P-001 收藏内容整理

## 能力提示词正文

阅读 normalized_content 和 evidence_bundle。先用一段话交代这条收藏讲了什么，再给可以迅速检查的概要和最多三项具体要点。每条摘要、概要、要点、拆解和概念都指向支持它的 evidence_id。原样返回证据编号，时间位置由 Folio 计算。概念用短词，尽量指明具体议题。

段落或字幕有明确层次时，沿原文顺序拆解。短材料用 compact；没有拆解必要时用 not_applicable、空 sections 并说明原因。照片的模型描述是间接证据，字幕也可能不完整。把内容缺失、读音歧义和转述局限写入 uncertainties。content_reliability_score 衡量当前归纳有多受提供的材料支持，区间为 0 到 1；它不是来源事实已经核实的概率。user_corrections 可指出要重看的地方，事实仍须有原证据。无法理解正文时直接返回 needs_input，指出下一步可补哪段材料。
